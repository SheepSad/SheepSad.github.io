自身技能

每条技能在前端都以毛玻璃卡片展示。点击下方的加号按钮即可无限增加自定义文本，还可以选择卡片尺寸来合并网格单元格。

尺寸说明：标准 = 1 格；横向合并 = 跨 2 列；纵向合并 = 跨 2 行；2×2 = 一次吃掉四个格子。 前端网格使用 grid-auto-flow: dense，合并后的空洞会自动被后面的卡片补上。

个人项目

每张项目卡片都是毛玻璃样式，点击整张卡片即可跳转。跳转链接留空时，会自动打开「个人资料」里填写的 GitHub 主页。

导入 / 导出

配置文件包含全部文字、主题设置与曲目信息，但不包含音乐文件本身（体积过大，无法放进 JSON）。

部署到 GitHub Pages（让线上显示和本地一致）

文字与音乐都存在浏览器本地（localStorage / IndexedDB），它们不会跟着代码上传。 所以直接部署后，访客看到的是占位模板。解决办法：把本地内容导出成 content.json 放到仓库根目录，线上首次访问会自动载入它。

  • 1. 点上面的按钮下载 content.json；
  • 2. 把它和 index.html、settings.html、css/、js/ 一起提交到仓库（目录结构不要改）；
  • 3. 音乐请把音频文件也放进仓库（例如 audio/ 目录），再到「音乐播放器」面板给每首曲子填写音频地址，例如 audio/song.mp3；
  • 4. 打开线上地址确认，必要时按 Ctrl+F5 强制刷新清缓存。
